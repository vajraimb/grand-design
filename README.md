# Grand Design

浏览器里的密度波旋涡星系。嵌套椭圆走出旋臂，粒子在盘上绕行；银河系标出银心、太阳、旋臂和大麦哲伦云。

## 运行

```bash
npm install
npm run dev
```

打开提示的本地地址。需要 Node 22。

## 操作

- 拖动轨道旋转视角
- `L` 开关地标
- 空格暂停
- `R` 重新抽样恒星
- `H` 隐藏界面

形态：银河系、仙女座、涡状星系、早型 Sa、晚型 Sc。侧栏可调缠绕、椭圆度、倾角和暗物质晕。

## 说明

这是示意图，不是星表。太阳标在猎户支约 8.1 kpc；背面旋臂会藏起来，转到近侧才出现。九大行星和星座不在这个尺度上。
